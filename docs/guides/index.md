Using a different board? claudrunner also ships adapters for **GitLab Issues, Azure Boards,
Shortcut, Asana, ClickUp, monday.com and Notion**. The setup is the same as the guides
above; the [configuration reference](../configuration.md) lists the settings and the
credentials for each one.
